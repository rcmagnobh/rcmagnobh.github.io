### 🚀 Sobre Mim

Sou um profissional de TI com **mais de 27 anos de trajetória sólida e consistente**, especializado em arquiteturas de alta performance e sistemas corporativos de missão crítica. Ao longo da minha carreira, transitei com sucesso por diferentes eras da tecnologia, o que me deu uma visão holística e profunda sobre o ciclo de vida do desenvolvimento de software.

Minha paixão está em resolver problemas complexos de negócios através de engenharia de software limpa, escalável e moderna. Atualmente, combino minha sólida base técnica com a aplicação estratégica de **IA Generativa e Engenharia de Prompt** (utilizando ferramentas como GitHub Copilot, Claude e Gemini) para acelerar entregas, otimizar processos de code review e elevar o padrão de qualidade do software.

* **Arquiteturas de Missão Crítica:** Desenvolvimento e sustentação de sistemas integrados de alta disponibilidade, lidando com grandes volumes de dados e regras de negócio altamente complexas.

* **Engenharia de Prompt Aplicada:** Pioneirismo no uso de copilotos de inteligência artificial aplicados ao desenvolvimento de software diário, maximizando a produtividade de equipes de engenharia sem comprometer a segurança ou os padrões arquiteturais.
